# Valkyrie Lab

Valkyrie Lab is a Python project scaffold generated by Codex. The repository is configured with a modern packaging setup, testing hooks, and tooling helpers to make it straightforward to start writing code immediately.

## Getting Started

1. Create and activate a virtual environment:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Upgrade packaging tools and install development dependencies:

   ```bash
   python -m pip install --upgrade pip
   pip install -e ".[dev]"
   ```

3. Run the default unit tests to validate the environment:

   ```bash
   pytest
   ```
